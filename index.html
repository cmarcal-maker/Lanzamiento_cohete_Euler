Modelo matemático

1. Ecuación de velocidad

dv/dt = T/m - g - (k/m)v

2. Ecuación de altura

dy/dt = v

3. Método de Euler

z(n+1) = z(n) + h*f(z(n))

4. Método de Heun

z* = z(n) + h*f(z(n))

z(n+1) = z(n) + h/2*(k1+k2)

5. Runge-Kutta de cuarto orden

z(n+1) = z(n) + h/6*(k1+2k2+2k3+k4)

6. Solución analítica

lambda = k/m

v(t)=v∞+(v0-v∞)*exp(-lambda*t)

y(t)=y0+v∞*t+(v0-v∞)*(1-exp(-lambda*t))/lambda

Justificación: RK4 normalmente es el método más preciso para el mismo tamaño de paso, seguido por Heun y Euler. Sus órdenes globales son O(h⁴), O(h²) y O(h), respectivamente.
